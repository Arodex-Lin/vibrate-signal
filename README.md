# 振动信号

一个纯静态网页:一台设备用**发送模式**点 A / B / C / D,另一台设备用**接收模式**分别振动 1 / 2 / 3 / 4 下。

## 用法

1. 两台设备打开网页,填同一个 6 位房间号(或在一台上点「分享」把链接发给另一台)。
2. 接收端切到「接收模式」,点「开始接收」,保持页面在前台。
3. 发送端点字母,接收端振动;发送端会显示「接收端已收到」。

## 说明

- 消息通过 [ntfy.sh](https://ntfy.sh) 公共服务中转,无需服务器和账号。房间号即频道,知道房间号的人都能发信号。
- 网页振动(Vibration API)只在 Android 上的 Chrome / Edge / 三星浏览器等可用。iPhone 上的浏览器都不支持,会改用提示音 + 闪屏提醒。
