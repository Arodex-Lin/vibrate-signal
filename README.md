# 振动信号

队友暗号小工具:一台设备用**发送模式**点 A / B / C / D,另一台设备分别振动 1 / 2 / 3 / 4 下。

网页:https://arodex-lin.github.io/vibrate-signal/

## 用法

1. 两台设备填同一个 6 位房间号(或在一台上点「分享」把链接发给另一台)。
2. 接收端:
   - **安卓 App(推荐)**:到 [Releases](https://github.com/Arodex-Lin/vibrate-signal/releases/latest) 下载 `vibrate-signal.apk` 安装,填房间号点「开始接收」,熄屏也能振动。
   - **网页**:切到「接收模式」点「开始接收」,需要保持页面在前台、屏幕亮着。
3. 发送端:
   - **单选**:点一个字母立即发送。
   - **多选**:点选几个字母后按「发送」,接收端按 A→D 顺序振动,字母之间停顿(默认 1.5 秒,可调)。例如 A C = 振 1 下,停顿,振 3 下。
   - **重置**:发错时点「✕ 重置」,接收端急促连振 8 下(网页端同时响两声低沉提示音,App 可选),表示上一个作废。
4. 接收端收到后会回执,发送端显示「接收端已收到」。

## 说明

- 消息通过 [ntfy.sh](https://ntfy.sh) 公共服务中转,无需服务器和账号。房间号即频道,知道房间号的人都能发信号。
- 网页振动只在安卓浏览器可用,iPhone 上的浏览器都不支持(会改用提示音 + 闪屏)。
- 安卓 App 由 GitHub Actions 构建([android/](android/)),推送 `android/` 下的改动会自动发布新版本。
